# CPA--

План площадки, где гарант держит деньги между заказчиком рекламы и исполнителем.

Заказчик хочет ровную сумму на кампании. Хочет $100, комиссия 10% сверху, к оплате $110, на кампанию падает $100. С выплаты исполнителю снимается ещё 10%. На выводе второй раз комиссию не берём.

Экран по настроению как тёмная криптобиржа: чёрный фон, крупные белые цифры, жёлтый акцент. Свои тексты и свой знак.

Первые 14 задач лежат в [plan/README.md](plan/README.md). Безопасность сделок и сайта в этот список ещё не входит, её разбираем отдельно.

GitHub Issues и Project отсюда не создались: у приложения Cursor есть доступ читать репозиторий, и нет права создавать задачи, метки и проекты. Новый токен в чат присылать не нужно. Нужно включить приложению Cursor права Issues и Projects на этот репозиторий. После этого эти же тексты можно перенести в задачи и колонки «Идея», «В работе», «Ожидание», «Выполнено», «Отказано».
