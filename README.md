# CPA--

План площадки, где гарант держит деньги между заказчиком рекламы и исполнителем.

Заказчик хочет ровную сумму на кампании. Хочет $100, комиссия 10% сверху, к оплате $110, на кампанию падает $100. С выплаты исполнителю снимается ещё 10%. На выводе второй раз комиссию не берём.

Экран по настроению как тёмная криптобиржа: чёрный фон, крупные белые цифры, жёлтый акцент. Свои тексты и свой знак.

14 задач созданы в Issues. Колонка — это метка `стадия: …`: идея, в работе, ожидание, выполнено, отказано. Доска Project этим ключом не создалась: у него нет права на проекты. Полные тексты по-прежнему лежат в [plan/README.md](plan/README.md).

Безопасность сделок и сайта в эти 14 задач не входит.
