# CPA--

Площадка-гарант между заказчиком рекламы и исполнителем. Заказчик платит за показы. Деньги лежат у площадки, пока показ не подтверждён. Доход площадки — комиссия с обеих сторон.

Сайта ещё нет. Сначала план в Issues. Этот файл — память для нового чата. Старый чат новый агент не видит.

## Новый чат

В первое сообщение новому чату вставь:

```
Прочитай README.md в Kisiusis/CPA--. Уже решённое не открывай заново.
Задача: …
```

Агент читает этот файл и открытые Issues. Потом делает только названную задачу.

## Какую Kimi выбирать

В чате Kimi над полем ввода три модели. «Обычная» для короткой работы — K2.6. Сильная — K3. Если в списке написано K3.1 Pro, это та же сильная модель, берите её. K3 Cluster для одной задачи не нужен: он для пачки дел сразу.

Интенсивность мышления:

- Стандартная — поправить текст, коротко ответить, пересказать задачу.
- Продвинутая — сделать одну задачу из Issues: код, правила, проверки.
- Экстремальная — только задачи про деньги и безопасность. Она дольше и тратит больше.

Промпт один и тот же:

```
Прочитай README.md репозитория и задачу №…. Уже решённое не меняй. Сделай только эту задачу.
```

K2.6 со стандартной интенсивностью — когда надо понять задачу или поправить формулировку. K3 с продвинутой — когда надо её реализовать. Экстремальную включайте на журнале денег, админке, платежах и журнале входов.

## Как зафиксировать стиль

Фраза «сделай как Bybit» или «как тот сайт» сама по себе вёрстку не держит. Другую нейросеть под вёрстку подключать не нужно. Та же K3 справится, если в задаче на экран есть три вещи:

- Два снимка: страница сделки с сайта-примера и тёмный экран Bybit. Их прикладывают к задаче файлом, не ссылкой «посмотри в интернете».
- Цифры стиля, их не выдумывать заново: фон почти чёрный, цифры белые и крупные, подписи серые, один жёлтый акцент на кнопке и полоске бюджета, плюс зелёный, отказ приглушённый красный, тонкая рамка карточки, небольшое скругление, слева меню, которое не уезжает.
- Запрет: не копировать чужой знак, чужие тексты и чужие картинки.

Слова про настроение модель понимает плохо. Снимок и эти цифры она соблюдает лучше.

## Уже решено

- Заказчик вводит сумму на кампанию. Хочет $100, комиссия 10% сверху, к оплате $110, на кампанию падает ровно $100.
- С начисления исполнителю снимается 10%. На выводе второй раз комиссию не берём.
- Минимум пополнения кампании $10, к оплате $11.
- Бюджет общий. Потолок «максимум одному человеку» режет его на ровные части. Личных конвертов «эти деньги закреплены за Васей» нет.
- Неистраченный остаток возвращается на кошелёк заказчика без второй комиссии. Комиссия при оплате не возвращается.
- Один материал оплачивается один раз. Заказчик не исполняет свою кампанию.
- Реклама только в коротких роликах: маленькая плашка в шортсе или полная интеграция в видео. Плюс готовый ролик, своё видео и нарезка. Площадки: TikTok, YouTube Shorts, Instagram Reels.
- Виджеты на сайтах не делаем и не отслеживаем.
- У сделки есть отдельное число: сколько раз открыли само объявление. Его видят заказчик и исполнитель. Это интерес, за него не платят. Платят только за просмотры ролика.
- У сделки с готовым материалом есть превью прямо на странице и одна кнопка скачивания. Один файл — «Скачать исходник». Несколько файлов — «Скачать все исходники», пачкой. Это то, что исполнитель добавляет в рилс. Внешняя ссылка на чужой диск не заменяет превью.
- В первой версии выплата не уходит сама. Сначала отсев мусора, потом кнопка гаранта.
- Баланс — сумма строк журнала. Число в ячейке руками не правят.
- Обычная регистрация не создаёт администратора. Вход в админку: пароль и код из приложения на телефоне. Код меняется каждые 30 секунд, его один раз привязывают QR-кодом. Код по СМС не используем. Запасные коды на случай потери телефона. Тот же код спрашивается ещё раз, когда из админки двигают деньги.
- Сообщение «оплата прошла» не зачисляет деньги, пока платёжный сервис не подтвердил его подписью.
- Спор: 48 часов заказчику, 7 дней молчания, сомнительную выплату можно держать до 30 дней. Отказ возвращает сумму в бюджет кампании.
- Экран по настроению тёмной криптобиржи, как Bybit: чёрный фон, белые крупные цифры, жёлтый акцент, зелёный плюс, тонкие рамки. Чужой сайт, чужой знак и чужие тексты не копировать. Язык интерфейса и задач — русский, простыми словами.

## Пока в плане, легко снять

Эти четыре можно перевести в 🚫 отказано, если не зайдут. Цифры в них рабочие.

- Ролик только с аккаунта, который исполнитель назвал заранее.
- Короткий код сделки в подписи ролика. Без кода выплаты нет.
- Перед кнопкой гаранта одна сводка: ссылка, просмотры, аккаунт, код, не повтор, хватает бюджета.
- Первая выплата не больше $50. Забрать деньги можно через 3 дня после кнопки. Рядом список «ждёт решения».

## Не делать, пока владелец сам не вернёт

- Магазин цифровых товаров. Там доказывают, что файл получен, а здесь — что рекламу посмотрели.
- Личный резерв бюджета под каждого исполнителя.
- Автоматическую выплату без кнопки гаранта.
- Второй способ вывода. Сначала один, его ещё не выбрали.
- Копирование экранов Prime Oracles.
- Виджеты на сайтах и свой счётчик показов сайта.
