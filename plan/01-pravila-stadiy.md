# ✅ Правила стадий

Стадия: ✅ выполнено. Метки: 📏 правила.

> Колонка задачи — это стикер-метка. Доски Project нет: у ключа нет такого права.

| Стикер | Когда ставить |
|---|---|
| 💡 идея | Записали, ещё не трогали |
| 🔧 в работе | Делаем сейчас |
| ⏳ ожидание | Нужен ответ, юрист или чужой сервис |
| ✅ выполнено | Решение записано в карточке |
| 🚫 отказано | Делать не будем. Причина — комментарий |

Остальные стикеры говорят тему: 💰 деньги, 📣 кампания, 👤 исполнитель, 🔍 проверка, 🎨 витрина, 📏 правила, 🔐 безопасность.
