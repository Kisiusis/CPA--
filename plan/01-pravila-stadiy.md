# Правила стадий доски

Стадия: выполнено. Метки: правила.

Колонка задачи написана в первой строке файла: «Стадия: …». Когда задачи переедут в GitHub, та же колонка станет меткой `стадия: …`.

- `стадия: идея` — записали, ещё не трогали.
- `стадия: в работе` — делаем сейчас.
- `стадия: ожидание` — нужен ваш ответ, юрист или чужой сервис.
- `стадия: выполнено` — решение записано в этой карточке.
- `стадия: отказано` — делать не будем. Причина пишется комментарием.

Отдельную доску GitHub Project приложение Cursor создать не смогло: у него нет права заводить проекты и задачи на аккаунте. Пока колонка написана в файле. Когда право появится, эти пять стадий станут колонками, текст задач не меняется.

Эта карточка сразу в «выполнено»: правила колонок зафиксированы.
