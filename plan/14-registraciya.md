# 🪪 Регистрация

Стадия: 💡 идея. Метки: 📏 правила.

> На старте для входа хватает почты и имени. Имя может быть псевдонимом.

Регистрация не делает человека администратором. Админ — отдельная карточка 🔐.

Проверка документа включается не сразу. Порог суммы пишет владелец. Список запрещённых тем и стран тоже пишет владелец. Чужой список запретов не копируем.

Пока порога нет, карточку можно перенести в ⏳ ожидание.

## Готово
- [ ] Есть порог, с какой суммы просить документ
- [ ] Есть черновик списка ограничений
