# 🔐 Админ отдельно

Стадия: 💡 идея. Метки: 🔐 безопасность.

> Обычная регистрация создаёт обычного человека. Администратора она не создаёт.

Админ — отдельный вход, только владельца. Ссылка на админку не торчит в общем меню.

Вход в админку просит пароль и код из приложения на телефоне. Код показывают один раз QR-кодом, телефон его запоминает. Дальше код сам меняется каждые 30 секунд. Подходят обычные приложения вроде Google Authenticator. Код по СМС не используем: его проще перехватить.

При настройке сайт показывает несколько одноразовых запасных кодов. Их записывают не в телефон. Если телефон потерян, вход остаётся через запасной код, и QR настраивают заново.

Тот же код приложение спрашивает ещё раз, когда из админки двигают деньги. Просмотр сделок повторный код не требует.

Чужая кампания не открывается сменой номера в адресе. Исполнитель не может вызвать «зачислить деньги» или «сделать меня администратором». Сервер каждый раз проверяет, что этот вход имеет на это право.

Каждое действие администратора пишется: кто вошёл, откуда, что изменил.

## Готово
- [ ] Админ не появляется из формы регистрации
- [ ] Вход в админку требует пароль и сменяемый код с телефона
- [ ] Запасные коды выданы при настройке
- [ ] Движение денег из админки спрашивает код ещё раз
- [ ] Действия админа попадают в журнал
