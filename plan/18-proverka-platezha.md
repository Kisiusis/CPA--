# 🧾 Платёж проверяется у сервиса

Стадия: 💡 идея. Метки: 🔐 безопасность, 💰 деньги.

> Сообщение «оплата прошла» само по себе деньги не зачисляет.

Его надо сверить с платёжным сервисом по их подписи. Иначе кто угодно пришлёт такое сообщение и получит сумму на кампанию.

От способа оплаты зависит вторая дыра, её ещё не закрыли выбором сервиса:

- Картой заказчик может потом забрать платёж через банк, а исполнитель уже получил выплату.
- Криптоперевод назад не отзывается, зато опаснее фальшивое «деньги пришли».

Пока способ не выбран, деньги исполнителя не уходят с площадки мгновенно. Это стыкуется с карточкой про кнопку гаранта.

## Готово
- [ ] Принято: зачисление только после сверки с платёжным сервисом
- [ ] Способ оплаты ещё открыт и живёт в карточке вывода
