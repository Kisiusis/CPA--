# 🔐 Журнал входов в админку

Стадия: идея. Меток нет, по просьбе владельца.

> Каждый вход в админку сам пишется в журнал. Странный вход присылает сигнал. Блокировка включается по правилам ниже, не на глаз.

Журнал смотрит только входы в админку. Обычные заходы заказчиков и исполнителей сюда не попадают.

## Что пишется в строке

- Время. В журнале хранится время UTC. Владельцу показывается время Екатеринбурга.
- IP.
- Устройство: браузер и система, как их прислал браузер. Пароль и код из приложения в строку не пишутся.
- Страна по IP.
- Итог: вошли, неверный пароль, неверный код, вход остановлен блокировкой.

Неудачные попытки пишутся так же, как успешные.

## Фильтры

В журнале можно оставить только:

- успешные входы
- неудачные попытки
- входы, по которым уже ушёл сигнал
- один IP
- одну страну
- промежуток дат

Пустой фильтр показывает всё, новые строки сверху.

## Сигнал

Сигнал уходит владельцу на почту и попадает в список «ждёт решения».

- IP, с которого этот админ ещё не входил.
- Страна, из которой этот админ ещё не входил.
- Вход с 01:00 до 07:00 по Екатеринбургу. Часы потом можно поменять.
- Пять неверных паролей или кодов за 15 минут, а затем успешный вход с того же IP.

Новая страна сама по себе вход не закрывает: владелец мог уехать. Сначала сигнал.

## Блокировка

- Пять неверных паролей или кодов за 15 минут с одного IP останавливают новые попытки с этого IP на 30 минут.
- Владелец может остановить IP прямо из строки журнала.
- Остановленная попытка тоже пишется в журнал.
- Снять остановку может только владелец.

## Готово

- [ ] У каждого входа есть время, IP, устройство, страна и итог
- [ ] Фильтры из списка работают
- [ ] Сигнал уходит по четырём случаям выше
- [ ] Чужая страна не блокируется сама
- [ ] Пять ошибок за 15 минут останавливают IP на 30 минут
- [ ] В журнале нет пароля и кода
